# ⚡ RESTOPANEL — Modern Restoran Yönetim Sistemi

Antrasit & mercan renk paleti ile tasarlanmış, dark mode destekli tam kapsamlı restoran yönetim uygulaması.

## 🚀 Özellikler
- 🔐 Admin paneli (menü yönetimi, stok takibi, veri analizi, kampanyalar)
- 🛍️ Müşteri paneli (sipariş, ödeme, puan sistemi)
- 🌍 3 dil desteği (Türkçe, İngilizce, İspanyolca)
- 💳 Kart & nakit ödeme akışı
- 📊 Günlük/haftalık/aylık analiz grafikleri
- 🏆 Altın/Gümüş/Bronz sadakat sistemi

## 🛠 Teknolojiler
React • Recharts • CSS-in-JS

## 🎨 Tasarım
Antrasit + Modern Mercan • Syne + DM Sans • Dark Mode
